# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in rig, please report it privately
by emailing a.prajjwal1729@gmail.com rather than opening a public issue.

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce
- Any relevant logs or proof-of-concept code

We will acknowledge receipt within a few days and work with you on a fix
and disclosure timeline.

## Supported Versions

As the project is in early development, only the latest release is
currently supported with security updates.
